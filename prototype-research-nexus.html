RN01 / 研究工作区

Research Nexus

让研究工具，回到同一个工作区。

把 alphaXiv、Zotero、OpenResearch 和 Google Drive 本地文件夹串进一套研究流程。从收藏论文、整理元信息，到归档 PDF，用系统模板减少反复切换。

  • 第一套文献研究模板：导入、配置、归档与去重。
  • 源码包含 DIY 设计器 Beta，可尝试搭建自己的流程。

INSTALL / WINDOWS SOURCE KIT

安装 Research Nexus v0.7.2

  1. 准备 Windows 10/11 x64、Node.js 22.12+、Python 3.10+（含 pip）及 Git。
  2. 下载新版源码 ZIP 与校验文件，核对 SHA-256 后解压到独立的可写目录。首次安装需要网络；包内没有账号、运行数据或第三方应用。
  3. 进入解压后的 research-nexus 文件夹，在 PowerShell 运行：
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
npm start

Setup 安装 Electron / Python 依赖并编译本地窗口组件。随后在 RN 的“系统模板”安装内置文献模板并配置自己的账号。自动构建器需自己的 Agent 授权，可能消耗模型额度。

升级前退出 RN（含托盘）并备份旧目录和 data；新版放到新目录，按指南迁移并核对配置。完整安装与升级指南 ↗ · SHA256SUMS.txt ↗
