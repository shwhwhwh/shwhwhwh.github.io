Codex · 想法管理

Task Pop

让每个想法，都有下一步。

想法很多，时间有限。把 Codex 中的项目和聊天加入一个有顺序的队列，发出当前消息后，继续推进下一项想法。

  • 从项目和聊天列表加入想法，拖动调整优先级，自定义整行颜色。
  • 查看未完成的想法与今日推进记录，由你标记完成。
  • 显示待用户输入、待用户批准等状态，按优先级处理需要你参与的任务。
  • 记录新想法，后台在选定的 Codex 项目下创建聊天。

按优先级处理眼前的一项。

把切换交给队列

排好想法

从 Codex 加入已有聊天，拖动排列。越靠上，优先级越高。

发送后继续下一项

启用自动切换。在队列中的聊天提交消息后，打开优先级最高、可继续的另一项。

由你决定何时完成

回合结束后想法仍保留。真正完成时，在面板选择它并标记完成。

等待输入和人工批准的自动提示需要面板保持打开。人工批准状态依赖 Codex 实时服务，异步提问状态依据本地聊天记录。具体兼容要求与限制见仓库说明。

安装 Task Pop

  1. 准备 Windows 上的 Codex 桌面版，以及带 Tk 的 Python 3.10 或更新版本。确认终端可以运行 python。
  2. 下载源码 ZIP 并解压到长期保留的目录。在解压后的项目根目录打开 PowerShell，运行下方命令。
codex plugin marketplace add (Get-Location).Path
  1. 在 Codex 插件目录选择 Task Pop（本地），安装 Task Pop。检查并信任 UserPromptSubmit、Stop、Interrupt 三条钩子。
  2. 双击 Task Pop.cmd 打开面板，从 Codex 加入想法，拖动排序，再启用“发送后自动切换”。

想减少完成提示打扰，可在 Codex 的通知设置中调整轮次完成通知。当前支持同一台 Windows 电脑上的本地聊天。完整安装与使用说明 ↗
